# Contributing

Bug reports, ideas and pull requests for Mauerbrecher are welcome. Please open an issue first for anything bigger than a small fix.

Before a pull request, `npm install`, `npm test`, `npm run typecheck` and `npm run check` pass (see the [README](README.md)). Code, docs and commit messages are in English; texts in the game exist in German and English.

Questions about the platform, the SDK or the dev tool belong in the [platform repo](https://github.com/hearthbit/gamehearth/issues).

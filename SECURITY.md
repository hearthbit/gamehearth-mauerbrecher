# Security

Please report security problems privately through GitHub: on this repo's **Security** tab choose **Report a vulnerability** ([direct link](https://github.com/hearthbit/gamehearth-mauerbrecher/security/advisories/new)). Do not open a public issue for them.

Problems in the platform itself (server, app, SDK, dev tool) belong to the [platform repo](https://github.com/hearthbit/gamehearth/security/advisories/new).
